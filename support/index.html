Support

For help with Frile, use GitHub Issues or email leowy.lwy@gmail.com. Include your macOS version, Frile version, and a description of what happened. Please do not send private files or folder contents.

Folder monitoring

Frile monitors only the immediate contents of folders you explicitly select. It does not add files that existed before permission was granted, and it does not monitor subfolders.
