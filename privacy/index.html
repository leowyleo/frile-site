Privacy Policy

Last updated: September 28, 2026

Information on your Mac

Frile stores preferences and security-scoped bookmarks for folders you choose in local app storage. It reads file names, types, sizes, and modification times in those folders to identify new files and show them to you. The recent-file list stays in memory while Frile runs.

Frile requests read-only access to folders you select. It watches only each selected folder's immediate contents, not subfolders. Existing files are not added when access is granted. You can disable or remove a folder in Settings.

When you choose Copy, Frile places the selected file URL on the macOS pasteboard so you can paste it into another app.

Collection and sharing

The current version has no account system, analytics, advertising, tracking, network sync, or third-party analytics SDKs. Frile does not send file contents, names, paths, or folder bookmarks to Leowy or other companies.
